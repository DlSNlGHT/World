# 记忆引擎 v1.1.1

## 更新日志

- 人物和实体记忆默认折叠，实体按组织、物品、能力和地点分类展示。
- 纪要和总述默认展开最新一条，点击卡片标题即可展开或收起。
- 实体支持别名，提取、归并和面板编辑均保留别名信息。
- 修复组合记忆请求的输出结构约束，并避免 API 已成功时因本地处理错误重复发送请求。
- 世界推演和记忆联动的运行提示按实际阶段串行展示。

## 可直接复制的发帖文案

【记忆引擎 v1.1.1 更新】

这次主要整理了记忆面板：人物和实体默认折叠，实体按类型分组，纪要和总述会默认展开最新一条。实体现在也支持别名。同时修复了组合提取的输出约束和 API 重试边界，世界与记忆联动时的运行提示也会按先后阶段正确展示。
