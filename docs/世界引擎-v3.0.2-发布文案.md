# 世界引擎 v3.0.2

## 更新日志

- 放宽事件链的早期创建条件。筹划、试探、调查起步和矛盾初现等已有具体迹象的事项，可以更早进入事件链。
- 放宽风声的传播起点。明确信息开始公开发布、被他人听闻或转述、经渠道传递或形成小范围议论后，即可建立风声。
- 保留事件与风声的归并、去重和合法传播边界，避免重复条目和私密信息泄露。
