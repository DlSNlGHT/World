# 记忆引擎 v1.1.0

## 更新日志

- 最新一轮记忆提取可追加近期正文、较早纪要和总述作为辅助参考，默认是 1 轮正文、5 条纪要、1 条总述。
- 新增“隐藏正文”开关。关闭后保留全部正文；开启后才按保留轮数隐藏已被摘要覆盖的旧正文。
- 纪要和总述不再截断 API 返回内容，API 默认最大输出调整为 65000。
- 人物、实体、纪要和总述支持折叠，API 结果保存后会自动刷新面板。

## 可直接复制的发帖文案

【记忆引擎 v1.1.0 更新】

这次增强了长对话记忆。总结最新一轮时，可以额外参考近期正文、较早纪要和总述；新增“隐藏正文”开关，不想隐藏时可以完整保留聊天正文。纪要和总述不再截断 API 返回内容，人物、实体、纪要和总述也都支持折叠，生成完成后面板会自动刷新。
